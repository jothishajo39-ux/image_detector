# Fake AI Image Detector

A client-side tool that analyzes uploaded images to heuristically detect signs of AI-generated/fake content — no backend required.

## 🚀 Features
- Upload and analyze images directly in the browser
- Heuristic-based analysis (no external API/backend dependency)
- Instant results, fully client-side for privacy

## 🛠️ Tech Stack
- HTML, CSS, JavaScript

## ⚙️ Installation
```bash
git clone https://github.com/jothishajo39-ux/image_detector.git
cd image_detector
```
Open `index.html` in your browser.
